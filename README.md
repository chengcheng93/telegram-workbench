# TG 多账号工作台

在本机浏览器中管理 Telegram 账号、聊天、联系人和任务。后台使用 Python / Telethon，最多管理 **8 个本人拥有的账号**，各账号的会话、配置和任务独立保存。

**第一次使用，请从[新手上手指南](docs/getting-started.md)开始。** 它包含下载、安装、登录、双账号测试，以及以后怎样重新打开和安全退出。遇到错误时查看[常见问题](docs/troubleshooting.md)。

已验证环境为 **macOS、Python 3.14、Telethon 1.45**。Linux 可尝试源码启动，但尚未完整实测；后台使用 `fcntl`，**Windows 当前不支持**。界面无需构建，Node 仅用于开发测试，不是运行依赖。

仓库中的 `.app` 和 `启动.command` 依赖原开发目录及独立运行环境，**不是通用安装包**。从 GitHub 下载后，请按上手指南从源码启动。

## 七个页面，分别做什么

操作前先核对固定账号栏和页面顶部身份。切换账号不会停止该账号已启动的后台监听。

| 导航入口 | 可以做什么 |
| --- | --- |
| 聊天 | 查看分账号或聚合会话，搜索已同步的本地消息，按需加载历史；发送文字、图片和文件，回复、编辑或撤回权限允许的消息；保存独立草稿；打开 AI 回复草稿辅助区 |
| 监听 | 为当前账号选择多个群，保存“仅预览”或“实际添加”配置；启动、暂停或停止；查看本次/累计统计、运行版本和处理原因 |
| 联系人 | 刷新、搜索和筛选联系人，维护备注、标签及邀请授权记录，手动添加或预览导入 CSV，删除选中项；切换到“批量邀请”或“联系人清理”标签 |
| 群组 | 查看当前账号可访问的群及权限，进入聊天，或将群选为监听范围 |
| 任务中心 | 预览并确认添加、删除、邀请或显式发送任务；查看逐项结果，暂停、取消、检查和恢复符合条件的任务，导出执行记录；创建 AI 任务草稿 |
| 账号管理 | 添加、登录、重新连接和命名账号；主动选择旧版配置进行迁移 |
| 设置 | 保存自己的 Telegram API 凭据，调整发送快捷键、通知和日志；配置可选 AI、锁定面板、清理本地消息缓存、备份应用数据及安全退出后台 |

## 使用前了解这些边界

- **监听从新消息开始。** 只处理启动或恢复边界后的实时新消息，不补抓历史、离线或暂停期间的发言，不抓取群成员列表，不自动发送问候私信。自己、机器人、匿名或频道身份、现有联系人和已成功处理者会被跳过。
- **预览不修改联系人。** 预览不写入成功去重记录；实际添加是单向保存，不表示双方互加或同意邀请。程序不增加手机号可见例外，请在 Telegram 中核对自己的隐私设置。
- **新登录账号默认停止监听。** 重启不会自动开始实际添加、重放未知请求或继续清空。删除联系人、清空联系人也不会清除成功去重记录；高级重置需单独确认。
- **AI 默认关闭，仅生成草稿。** 启用后，只有明确选择并同意的数据会发送给配置的服务。回复仍需人工发送，任务仍需预览确认；没有 AI 自动回复。
- **结果未知时先核实。** 网络中断、超时或重启后的“未核实”不能当作失败，不能盲目重复发送、添加、邀请或删除。停止/取消只阻止后续请求，已经提交的请求仍可能完成。
- **等待与权限由 Telegram 决定。** 已知等待时间未到不能提前解除；未知时长限制需人工检查。邀请结果区分已核实加入、原已加入、受限、失败和未核实，没有可承诺的固定安全每日额度。

## 联系人清理的范围

“删除选中”和“全部清空”是不同流程。清空只作用于所选账号的联系人，不删除聊天、不拉黑、不移出群；准备清空会先停止本账号添加、排空在途请求、核对范围并生成本机备份，最终删除需要重新确认账号名称与风险。

完整保存号码读取取决于 Telegram 的 takeout 导出能力；`saved_count` 不能直接当作未注册号码数，返回号码也没有注册状态字段。范围无法可靠核实或导出要求等待时，程序会显示 **“不支持完整清空”并阻止最终删除**，不会把不完整结果称为全部完成。

联系人清空备份仅包含可导出的已注册联系人，**没有一键恢复**。确认前数据变化、备份不可读或摘要不符都会使确认作废；清空取消、中断或完成后，监听保持停止。其他 Telegram 客户端的联系人同步可能再次导入数据。

## 本机保存与运行

上手指南会要求每次显式设置同一个 `TG_WORKBENCH_STATE_DIR`。该目录保存账号会话、应用凭据、配置、草稿和执行记录；不要上传仓库、放入共享目录或发给他人。源码不含预配置凭据、已登录账号或运行数据库。

面板只监听本机 `127.0.0.1`，后台仍需联网连接 Telegram。关闭网页或锁定面板不会停止后台；顶部“暂停全部自动化”用于暂停新自动化写入，“设置 → 退出后台程序”用于安全退出。设备需要保持唤醒与联网，没有安装开机自启，也不承诺关机或休眠时运行。

旧版迁移只在你主动选择来源后进行：先私有备份和复制，再核实身份与预览，确认后新增独立账号。它不覆盖已有账号，不能迁移旧版未持久保存的统计或成功去重；导入后保持预览配置和停止状态。也可直接重新登录，不迁移旧会话。
